# WiFi Hub (blueprint)

A prepaid Wi-Fi billing system for a home server: captive portal, customer accounts, wallet, MoMo / Paystack / voucher top-ups, time and data plans, automatic cut-off, promotions, giveaways and customer support.

This folder holds the **blueprint** for Claude Code to build it from:

- `CLAUDE.md`: rules Claude Code follows while building.
- `docs/BLUEPRINT.md`: the full specification (network, architecture, database, payments, pages, API, phases).

## Build it with Claude Code

```bash
cd wifi-hub
claude
```

Then type:

> Read CLAUDE.md and docs/BLUEPRINT.md. Build Phase 0 and Phase 1 from §21. Stop after Phase 1 and show me the acceptance checks.

Continue with "Build Phase 2", "Build Phase 3", and so on up to Phase 6.
